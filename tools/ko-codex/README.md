# 국어 Codex 연결 — Better-BMAPS 시험 기능

기존 국어 화면의 `분석`은 그대로입니다. 새 `Codex 분석`은 **같은 PC**에서 실행 중인 로컬 처리 프로그램으로 PDF를 보내고, Python 원본 영역 추출 → Codex 원본 검토 → 등록 초안 미리보기를 수행합니다. 이 채팅창에 메시지를 보내는 방식이 아닙니다.

## 실행

1. Python과 Codex CLI를 준비하고 `python -m pip install -r requirements.txt`, `codex login`을 실행합니다. 기존 ChatGPT 로그인을 재사용합니다. 별도 API 키를 코드에 넣지 않습니다.
2. 최초 한 번 Better-BMAPS 체크아웃에서 아래 명령으로 사용자 로그인 시 자동 실행을 설정합니다. 주소는 사용하는 테스트 사이트의 HTTPS 주소입니다.

   ```powershell
   ./tools/ko-codex/install-startup.ps1 -Origin 'https://실제-Better-BMAPS-주소'
   ```

3. 사이트의 `Codex 연결`을 누르고 열린 로컬 창에서 요청 사이트 주소를 확인한 다음 `이 사이트 연결 허용`을 누릅니다. 연결 코드 입력과 CMD 창 유지가 필요 없습니다. 연결 창은 최소화해 두세요. 팝업이 차단되면 브라우저에서 허용해야 합니다.
4. PDF와 문항 범위를 선택하고 `Codex 분석`을 누릅니다. 첫 시험은 작은 범위로 진행하세요. 전 범위를 검사하면 여러 번의 Codex 호출과 계정 사용량이 발생합니다.
5. 결과에서 원본 지문·문항 이미지와 Codex 검토 의견을 확인하고 `등록 초안 내려받기`로 JSON을 보관합니다.

페이지를 새로고침했다면 다시 연결을 허용하고 `결과 다시 받기`를 누릅니다. 처리 프로그램 자체를 재시작한 경우 새 분석이 필요합니다. 한 번에 한 작업만 처리합니다. 로컬 창의 종료 버튼으로 처리 프로그램을 종료할 수 있습니다. PC가 켜져 있고 Windows에 로그인되어 있어야 합니다.

자동 실행 해제는 같은 설치 명령에 `-Remove`를 추가합니다. 수동 백그라운드 시작은 `start.ps1 -Origin 'https://실제-Better-BMAPS-주소' -Background`입니다. 설치된 바로가기가 이 체크아웃을 참조하므로 폴더를 이동하면 재설치하세요. 시작 오류는 사용자 폴더 `.bmaps-ko-worker/worker-error.log`에서 확인합니다. 이전 연결 코드 방식은 고급 설정에 남겨 두었습니다.

## 현재 범위

- 텍스트형 PDF, 최대 30MB/40쪽. 문제 범위는 기존 화면 값을 따릅니다.
- Python이 각 단·페이지의 영역을 결정합니다. Codex는 선택 범위의 모든 원본 페이지를 네 쪽씩 검토하여 누락·잘림·연결 문제를 보고합니다. 자동 수정 또는 정확성 보장은 없습니다.
- Codex 실패를 성공으로 표시하지 않습니다. 로그·페이지 이미지·완료 결과는 로컬 사용자 폴더 `.bmaps-ko-worker/<작업ID>`에 남습니다. 보관이 필요 없으면 프로그램 종료 후 해당 작업 폴더를 삭제하세요.
- **정답 PDF 업로드·학생 배포·DB 시험 등록은 이 연결 단계에 포함되지 않습니다.** 기존 국어 화면 역시 DB 저장이 없으며, 이 변경은 등록 초안을 만드는 기능입니다. 새로운 DB 테이블이나 Supabase DDL을 실행하지 않습니다.
- 다른 PC에서 작업 요청을 보내는 HQ 큐는 아직 없습니다. 로컬 서버는 `127.0.0.1:8765`에만 바인딩하며 인터넷에 공개하거나 LAN 주소로 변경하지 마세요.
- 로컬 창은 사용자 승인 후에만 요청한 사이트와 통신하며 메시지의 Origin과 창을 검증합니다. 인증 코드는 로컬 창 안에만 있고 사이트에는 보내지 않습니다. 실제 처리 요청은 로컬 창에서 같은 출처로 보내므로 기존 사이트→로컬 직접 요청을 대체합니다. 서버는 Host와 인증 코드를 검증하고 외부 프레임 삽입을 차단합니다. 문서는 고정된 검토 프롬프트에 데이터로만 전달하고 Codex는 읽기 전용으로 실행합니다. 로그인 인증 파일이나 연결 코드를 저장소에 올리지 마세요.

공식 방식: https://developers.openai.com/codex/noninteractive
