# 관리자 원본 교재 구축 — 프리뷰 1단계

`변형문제 → 관리자 원본 교재 구축` 또는 `/source-library.html`.
현재 BMAPS의 활성 admin 계정으로 접속한다. 기존 포텐셜 HWPX 생성기는 그대로 유지한다.

## 흐름

1. 교재명·과목·학년·개정판, 문제 PDF(필수)·답지 PDF(선택)를 등록한다.
2. 원본을 선택하고 PDF 페이지 범위를 지정한다. 파일당 50MiB, 1~1000쪽, 한 번에 최대 5쪽.
3. Codex 연결을 허용하고 추출한다. 처리기 v7의 `source` capability가 필요하다.
4. 시작 쪽이 범위에 포함된 문항을 읽는다. 앞뒤 1쪽은 이어지는 문제 확인에 사용한다.
5. 추출 결과는 후보로 저장한다. 기존 수동 수정본을 자동 덮어쓰지 않는다.
6. 문제 후보는 검수 문항으로 추가한다. 답지 후보는 관리자 선택으로 원문에 연결한다.
7. 본문·선지·단원·번호·인쇄 페이지·정답·해설·그림을 수정하고 원본 대조 체크 후 사용 가능으로 확정한다.
8. 사용 가능 문항 중 출력 체크한 1~100개를 HWPX로 출력한다. 본문은 텍스트, `$…$`는 실제 한글 수식, 도형은 PNG.

## 저장

- 새 SQL 불필요. 기존 `variant_docs`와 비공개 `variants` 버킷을 사용한다.
- 신규 문서는 `source_type='원본교재'`, `file_kind='pdf'`. `file_path`는 원본 PDF가 아니라 **교재 manifest JSON** 경로다.
- 기존 `variant.html` 목록에서 원본교재를 제외하여 기존 HWPX 파서로 잘못 보내지 않는다.
- `library/<book-id>/files/<id>.pdf`: 문제/답지 원본. 등록 후 원본을 덮어쓰지 않는다.
- `library/<book-id>/images/<id>.png`: 도형 이미지. manifest와 분리하여 전체 이미지 재업로드 방지.
- `library/<book-id>/revisions/<id>.json`: 문항·후보·원본 위치·추출 범위·검수 상태의 불변 저장본.
- DB pointer는 기존 file_path와 일치할 때만 갱신한다. 동시 수정 충돌은 오류로 표시하고 편집창을 유지한다.
- 이전 revision은 유지한다. 현재 UI는 최신본 다시 열기와 JSON 백업을 제공하며, 이전 revision 복원 UI는 아직 없다.
- 저장 실패로 생성된 미참조 파일은 자동 삭제하지 않는다. 향후 보존 정책 필요.
- 계정 인증·Storage/RLS 정책은 기존 BMAPS 체계를 그대로 사용한다. 클라이언트 admin 검사는 서버 인증을 대체하지 않으며, 이번 작업은 기존 인증 체계를 개편하지 않는다.

## 실행·검증

- `source_pipeline.py`는 `exam_pipeline.ask`의 Codex CLI 구조화 출력을 재사용한다. 문서 지시를 실행하지 않고 shell 도구를 끈다.
- `extract`, `answers`, `export`가 `/jobs?kind=source`로 처리된다. export에는 AI 호출이 없다.
- 작업 ID는 교재·사용자별 localStorage에 보관한다. 새로고침 후 연결을 허용하고 ‘진행 작업 다시 확인’으로 완료 결과를 가져온다.
- 완료된 결과는 applied_jobs로 중복 반영을 방지한다. 프로세스 종료로 미완료 작업이 사라진 경우 기록 해제 후 재요청한다. 자동 작업 재개/3경로 병렬은 다음 단계다.
- Python 26개 회귀 테스트, `test_source_ui.cjs` 및 기존 내신/국어/N제 브라우저 모의 테스트.
- 자체 2문항 PDF를 실제 Codex로 추출해 본문/정답2개·그림1개 확인. HWPX를 실제 한글에서 PDF로 변환하고 수식·그림 시각 확인.
- 실제 116쪽 교재의 전사 정확도는 아직 측정하지 않았다. 116쪽 범위 제한 처리는 합성 문서로 검증했다.
- 브라우저 테스트는 외부 DB 저장을 모의 처리한다. 실제 계정의 Storage 정책·용량 설정과 업로드 저장은 관리자 현장 테스트가 필요하다.

## 이번 단계의 범위

PDF 교재 구축, 답지 추가/연결, 검수, 원문 HWPX 출력까지. 새 변형 생성, 공용 원격 PC 작업 대기열, 3경로 병렬, 학생 배포는 포함하지 않는다.
복잡한 표/다단/장문 연결은 검수가 필요하다. 인식된 원문과 그림 영역은 자동 확정하지 않는다.
